Numerical probes

Seven results from openai/math, computed

The collection holds 722 manuscripts in 372 families, produced by an internal OpenAI model. Most concern objects that cannot be computed at all. These seven can: each animation plots the quantity its theorem is about, next to the value the theorem predicts, so you can watch the gap close.

Nothing here verifies a proof. Where a computation agrees with a manuscript it is evidence about the statement, not the argument.

Source: github.com/eigendash/openai-math-visualised. Every series is regenerated by scripts/build_site_data.py; the static figures and the test suite live in the same repository.
